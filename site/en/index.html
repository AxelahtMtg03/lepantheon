Student project · Steam interface redesign

All your games. All your legends.

Pantheon is an alternative interface for Steam on Windows. It puts your achievements and progress at the center, with a dark, airy design free of visual noise. Steam stays your client: Pantheon is just a new face for it.

Discover the project Try it
The project

A Steam client designed for collectors

Steam is complete, but its interface is dense, and achievements are buried several clicks deep. This student project started from a simple question: what would Steam look like if it were designed for people who chase 100%?

I designed the visual identity, the screens and the design system, then coded them into a real Windows application (Electron) that reads Steam’s local files and uses your own access to the official API.

Pantheon doesn’t replace Steam: it keeps running in the background, and games launch through Steam as usual.

A single blue accent, reserved for actions and progress. Everything else steps aside for the covers.The guiding principle of the design

Features

Every screen serves progress

Library

Covers, space, a single action

The grid puts covers front and center. On hover, a round Play button appears in the middle. Your last played game is pinned at the top so you can resume in one click.

  • Search, filters (installed, downloads, favorites, almost complete) and sorting
  • Install state and download progress on every cover
  • Smooth with hundreds of games
Game page

Achievements, finally readable

A progress ring, unlocked achievements with their date, and a rarity always spelled out in words: Common, Uncommon, Rare, Ultra rare. Never just a color.

  • Filters All, Unlocked, Locked, Rare, sort by rarity
  • The most accessible achievement and the rarest one you earned
  • The game’s official artwork as the backdrop, fading into the interface
Achievements page

The Pantheon of finished games

An overview of your collection: total unlocked, a “Gods” section for games completed at 100%, the games closest to the finish line and the rarest achievements you’ve earned.

Store

Browse without leaving the app

Specials, top sellers, new releases and search, read-only. Purchases are always made in the real Steam, one click away with “View in Steam”.

Friends and downloads

Who’s playing what, and how your install is going

Your friends sorted by status with the game they’re playing, and a Chat button that opens the conversation in Steam. Ongoing downloads show their progress, all the way to a badge in the menu.

Screenshots show the author’s own Steam library. The friends screen uses fictional friends.

Getting started

Up and running in a few minutes

Pantheon works right away with the games you have installed. A free Steam API key unlocks the rest: games you own but haven’t installed, your achievements and your friends.

  1. Have Steam installed

    Install Steam and sign in as usual. Pantheon reads Steam’s local files and never asks for your password.

  2. Install Pantheon

    Run the installer. Because it isn’t signed, Windows may warn you: click “More info” then “Run anyway”.

  3. Open it

    Your installed games appear straight away, with your playtime.

  4. Add your key (optional)

    Follow the guide below to see all your games, achievements and friends.

Get your free Steam API key

  1. Sign in to Steam in your web browser, then open the key page with the button below.
  2. In “Domain Name”, simply type: localhost
  3. Accept the terms and click “Register”.
  4. Copy the 32-character key that appears.
  5. In Pantheon, open Settings → Steam API key, paste it and click “Save the key”.
Open the Steam key page

To see your achievements and friends, set “Game details” and “Friends list” to Public in Steam (Profile → Edit Profile → Privacy Settings), and untick “Always keep my total playtime private”.

The key is personal: never share it. Pantheon keeps it encrypted on your computer and sends it only to Steam.

Under the hood

Beautiful, but also safe

An interface that reads your library has to be flawless on security. This project was built with the same rigor as the design.

Never a password

No Steam sign-in. The app reads local files and uses your own API key, encrypted on your computer with the Windows vault.

Hardened Electron

Context isolation, sandbox, strict security policy, Steam links limited to an allow-list of actions, network restricted to a few domains.

Zero collection

No account, no usage statistics, no server: everything stays on your PC. Calls to Steam are cached and capped.

Tested

48 automated tests cover the Steam file reader, rarity calculations, link validation, the cache, the API client and the translations.

Demo mode

One variable is enough to run everything on fake data, without Steam, which is handy for testing and demos.

Fast

Lazy-loaded images, targeted card updates and off-screen rendering keep hundreds of games smooth.
