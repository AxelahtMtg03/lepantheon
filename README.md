# Le Pantheon

Remplaçant esthétique de l'interface Steam pour Windows (Electron). **Non affilié à Valve ni à Steam.**
Ne demande jamais le mot de passe Steam. Aucune télémétrie.

## Commandes
- `npm install` : installe les dépendances (si Electron manque : `node node_modules/electron/install.js`)
- `npm start` : lance l'appli
- `npm run demo` : mode démo avec de fausses données (aussi `PANTHEON_MOCK=1`)
- `npm test` : tests automatiques
